# 🛡️ Black Hat Python - Estudos & Laboratórios

Repositório dedicado aos meus estudos práticos e desenvolvimento de scripts baseados no livro **"Black Hat Python: Python Programming for Hackers and Pentesters"** (2ª Edição). 

O objetivo deste repositório é documentar a implementação de ferramentas de rede, manipuladores de pacotes, automações e conceitos de segurança ofensiva utilizando Python em ambiente controlado (Kali Linux).

---

## 📂 Estrutura do Repositório

Os scripts estão organizados de acordo com os capítulos e conceitos abordados no livro:

* **`Cliente_TCP.py`** - Implementação de um cliente TCP básico para testes de conexão e interação com sockets.
* *(Novos scripts serão adicionados conforme avanço nos capítulos)*

---

## 🛠️ Tecnologias e Ambiente

* **Linguagem:** Python 3
* **Sistema Operacional:** Kali Linux
* **Ambiente Virtual:** `venv`
* **Ferramentas:** VS Code, Git / GitHub
